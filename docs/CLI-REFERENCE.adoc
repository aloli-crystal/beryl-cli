== Sous-commandes (alias courts)

Chaque commande est utilisable sous sa forme longue ou sa forme courte :

[cols="2,1,4",options="header"]
|===
|Commande |Alias |Description

|`help` |`h` |Aide globale ou d'une sous-commande (ex: `beryl h rescue`)
|`init` |`i` |Initialise `~/.beryl/<société>/` + propose providers/domaines
|`add-provider` |`ap` |Ajoute un fournisseur à une société (credentials)
|`add-domain` |`ad` |Ajoute un domaine à une société (zone DNS)
|`list-hosts` |`ls` |Liste les hôtes de toutes les sociétés
|`show` |`sh` |Détails d'un hôte (config mergée complète)
|`rescue` |`r` |Bascule un hôte en rescue via l'API hébergeur
|`boot-hd` |`bh` |Bascule sur le disque via l'API (inverse rescue)
|`wipe` |`w` |Efface un disque sur un hôte en rescue
|`bootstrap` |`b` |Installe FreeBSD 15 (mfsBSD-in-QEMU)
|`scan` |`s` |Détecte les disques et propose un YAML host
|`apply` |`a` |Synchronise packages/users/clés SSH
|`prep-rescue` |`pr` |HTTP local pour préparer un rescue Debian
|`bake-seed` |`bs` |cloud-init seed.img pour Ubuntu Server live
|`version` |`v` |Affiche la version
|===

== Options globales

[cols="2,1,4",options="header"]

|Long |Court |Description

|`--config=PATH` |`-c` |Racine de configuration (défaut : `~/.beryl`)
|`--help` |`-h` |Aide globale
|`--version` |`-v` |Version de beryl
|===

== Exemples de combinaisons courtes

[source,console]
----
# Init d'une société et ajout de fournisseurs/domaines
beryl i aloli
beryl ap aloli/ovh
beryl ap aloli/scaleway
beryl ad aloli/aloli.net

# Opérations sur serveur (forme courte + flags courts)
beryl r ns3156789.ip-51-83-6.eu -d aloli.net
beryl s ns3156789.ip-51-83-6.eu -d aloli.net -D -w
beryl b loulou.aloli.net
beryl w loulou.aloli.net -A    # wipe tous les disques déclarés
beryl a loulou.aloli.net

# Version / aide
beryl -v
beryl h ap
----

== Maintenance de ce tableau

Ce fichier est la source de vérité pour les shorts. Toute nouvelle
commande ou nouveau flag doit :

. Avoir un short défini dans le code (`p.on("-X", "--option", ...)`)
. Être ajouté dans ce fichier
. Être vérifié par un grep du type :

  grep -rn "p\\.on(" src/beryl/cli/ | grep -v "\"-[a-zA-Z]" | grep "\"--"

qui doit ne rien retourner. Les sous-commandes ajoutées dans `cli.cr`
doivent avoir une entrée dans la table `SUBCOMMAND_ALIASES`.
