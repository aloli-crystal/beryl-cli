=== Pivot bootstrap — ADR-010 / ADR-011 (avril 2026)

Le test grandeur nature du 19 avril 2026 sur un Kimsufi OVH UEFI-only
a révélé que l'ISO mfsBSD `dd`-ée n'est pas amorçable par un firmware
UEFI (ADR-010). Le test manuel du 20 avril a validé end-to-end la
voie de remplacement : FreeBSD est désormais installé *depuis* le
rescue Linux via une VM QEMU en passthrough disque (ADR-011).

==== Ajouté

* `Beryl::Bootstrap::QemuInRescue` : classe unifiée qui remplace le
  couple `MfsBSD` + `Installer`. Orchestre apt → ISO → remasterisation
  xorriso → OVMF → QEMU (-no-reboot, UEFI, KVM, passthrough disque)
  → `reboot -f` → attente SSH.
* Template `templates/installerconfig.sh` : format bsdinstall en deux
  parties (variables ZFSBOOT + distributions pkgbase, puis post-install
  chroot pour `rc.conf` en `ifconfig_DEFAULT`, `fstab` en labels GPT,
  users `admin`/`deploy`, sudoers wheel NOPASSWD, clé SSH, poweroff).
* CLI `beryl bootstrap` : nouveau flag `--iso-url` et
  `--freebsd-version`, et `--installed-user` (défaut `admin`,
  `PermitRootLogin no` respecté).
* Specs : 24 nouveaux specs pour `QemuInRescue` (render, base64, qemu
  command line, argument validation). Total : 54 specs verts.

==== Déprécié

* `Beryl::Bootstrap::MfsBSD` et `Beryl::Bootstrap::Installer` : restent
  compilés pour un éventuel support Legacy BIOS, mais ne sont plus
  appelés par `beryl bootstrap`. En-tête de fichier marqué DEPRECATED
  avec pointeur vers ADR-010 / ADR-011.

==== Documentation

* `ARCHITECTURE.adoc` ADR-003 passé à « Superseded by ADR-011 ».
* `TESTING.adoc` : sections UTM, OVH et Scaleway réécrites pour le
  nouveau flux (plus de `prep-rescue`, plus de `dd` bare metal, simple
  `beryl bootstrap <host>` pendant 25-35 min).

=== Ajouté

==== Fondations du projet

* Squelette initial (shard.yml, LICENSE MIT, README bilingue FR/EN).
* Document d'architecture link:ARCHITECTURE.adoc[ARCHITECTURE.adoc] avec 11 ADR fondateurs :
  FreeBSD 15 pkgbase, agentless SSH, bootstrap mfsBSD + dd (superseded
  par QEMU-in-rescue), recettes YAML composables, conventions Mozilla
  Modern, idempotence.
* Convention Aloli : branche par défaut `production`, `development` après la première version.

==== Phase 1 — Bootstrap Linux → mfsBSD → FreeBSD 15 (MVP)

* `Beryl::SSH` : wrapper agentless autour des binaires `ssh` / `scp`
  systèmes. Connection, Result, CommandFailed, insecure_bootstrap
  (pour la bascule mfsBSD où la clé d'hôte change).
* `Beryl::Inventory` : chargeur YAML d'hôtes avec defaults + overrides,
  `find` / `find?`, construction de `SSH::Connection` depuis un `Host`.
* `Beryl::Bootstrap::MfsBSD` : bascule un rescue Linux vers mfsBSD via
  `dd` + reboot + attente SSH. Image par défaut : depenguin.me FreeBSD 15.
* `Beryl::Bootstrap::Installer` : installe FreeBSD 15 en pkgbase sur
  ZFS (partition EFI + swap + pool zroot). Script shell embarqué à
  la compilation (macro `read_file`), clés SSH en base64.
* `Beryl::CLI` : sous-commandes `list-hosts`, `show`, `bootstrap`, `version`.

==== Tests et documentation

* 28 specs Crystal (SSH, Inventory, Bootstrap) — tous verts.
* link:TESTING.adoc[TESTING.adoc] : guide de test grandeur nature
  (UTM local, OVH dédié, Scaleway Dedibox).
* CI GitHub Actions : format Crystal + specs sur Linux et FreeBSD 15
  via `cross-platform-actions/action`.
